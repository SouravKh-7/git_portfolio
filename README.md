# Sourav Khandai | IT, Automation & Industrial AI Project Portfolio

Hey, I’m **Sourav Khandai**.

This repository is a collection of projects where I explore how **IT, automation, mechanical systems, design workflows, and industrial AI** can be used to solve practical real-world problems.

My background is in **Mechanical Engineering**, with exposure to the **bearing manufacturing industry**. That experience helped me understand how industrial systems work in practice — machines, production processes, quality checks, defects, downtime, maintenance, inspection records, and process improvement.

Through this portfolio, I try to connect that engineering understanding with digital and automation-based solutions. The focus is on building projects that are useful, practical, and connected to real industrial or engineering use cases.

---

## About This Portfolio

This portfolio is not just a list of tools or technologies. It is a collection of project ideas, experiments, and practical workflows that show how a problem can be understood, structured, and improved.

In every project, I try to think from both sides:

- the **engineering side**, where the problem comes from machines, processes, products, design, inspection, or operations
- the **IT and automation side**, where the problem can be improved using data, software, workflow automation, or AI-based methods

The main idea is to ask:

- What is the actual problem?
- Why is this problem important?
- What information is needed to understand it?
- Can the process be measured?
- Can repeated manual work be reduced?
- Can data reveal patterns, defects, or risks?
- Can automation make the workflow faster or more reliable?
- Can AI help with prediction, classification, or decision support?
- How can the solution be improved for real industrial use?

## Project Areas

## 1. IT & Data-Driven Projects

These projects focus on using information properly.

In many industries, useful data is available in reports, files, records, inspection sheets, machine logs, production entries, and maintenance notes. But if this information is not organized, it becomes difficult to use.

These projects explore how data can be collected, cleaned, structured, analyzed, and converted into useful outputs.

**Example areas:**

- Operational data analysis
- Production data analysis
- Quality and inspection data
- Process tracking
- Report preparation
- Decision-support systems
- Structured data workflows

**Why this matters:**

Good decisions need clear information. These projects show how raw or scattered data can be converted into something useful for analysis, reporting, or improvement.

---

## 2. Automation Projects

These projects focus on reducing repetitive work.

Many tasks in engineering and industrial environments are repeated again and again, such as preparing reports, checking records, cleaning data, updating files, tracking process status, or generating summaries.

Automation projects explore how such tasks can be simplified and made more consistent.

**Example areas:**

- Report automation
- Data cleaning workflows
- Repeated task automation
- Process tracking automation
- Inspection report preparation
- Workflow improvement
- File and document processing

**Why this matters:**

Automation saves time, reduces manual errors, and improves consistency. These projects show how simple systems can make everyday work more reliable.

---

## 3. Mechanical & Design Automation

These projects connect mechanical engineering with digital workflows.

Design and engineering work often involves calculations, parameter changes, comparison of alternatives, simulation results, and repeated design checks. These steps can often be organized or automated to make the process faster and more efficient.

**Example areas:**

- Engineering calculation automation
- Design workflow automation
- Parameter-based design studies
- Simulation result organization
- CAD/design process improvement ideas
- Design comparison workflows
- Basic optimization of design parameters

**Why this matters:**

Engineering design is not only about creating a model. It also involves checking conditions, comparing options, validating results, and improving the design. Automation can help make these steps faster, clearer, and easier to repeat.

---

## 4. Manufacturing & Bearing Industry Projects

These projects are inspired by my exposure to the **bearing manufacturing industry**.

Bearing manufacturing involves precision, quality control, inspection, machine performance, defects, rejections, maintenance, and process consistency. Even small problems in manufacturing can affect quality, cost, and delivery.

These projects explore how industrial data can be used to understand and improve such problems.

**Example areas:**

- Bearing defect analysis
- Rejection and quality variation study
- Machine downtime tracking
- Maintenance-related analysis
- Production performance analysis
- Inspection record analysis
- Process improvement studies

**Questions I explore:**

- Which defect occurs most often?
- Which process step has more rejection?
- Is machine downtime increasing?
- Can inspection data show hidden patterns?
- Can maintenance be planned before failure?
- Can production performance be tracked more clearly?

**Why this matters:**

Manufacturing problems are practical and measurable. These projects help connect real industrial experience with data analysis, automation, and improvement thinking.

## 5. Industrial AI Projects

These projects focus on applying AI ideas to industrial problems.

Industrial AI is about using data from machines, processes, inspections, sensors, and operations to support better decisions. The goal is not only to build a model, but to understand how the model can help in a real workflow.

**Example areas:**

- Defect classification
- Failure prediction
- Quality prediction
- Anomaly detection
- Predictive maintenance
- Process monitoring support
- Industrial decision support

**Why this matters:**

In industrial environments, AI can help identify patterns that are difficult to see manually. It can support maintenance planning, quality improvement, defect detection, and process optimization.

---

## 6. Drone & Path Optimization Projects

These projects focus on drone movement, inspection planning, and route optimization.

Drones can be used for inspection, monitoring, mapping, and safety checks in industries, construction sites, warehouses, farms, solar plants, and infrastructure areas. But for practical use, drones need to follow safe and efficient paths.

These projects explore how drone movement can be planned and improved.

**Example areas:**

- Drone route planning
- GPS path analysis
- Inspection-point coverage
- Battery-aware path planning
- Industrial inspection route optimization
- Area coverage planning
- Drone inspection workflow ideas

**Questions I explore:**

- What is the best path to cover inspection points?
- How can unnecessary travel be reduced?
- Can battery usage be considered while planning the route?
- Can GPS data help improve future paths?
- Can inspection points be prioritized?
- Can route planning make drone inspection safer and more useful?

**Why this matters:**

Drone path optimization connects automation, data, engineering, and real-world inspection. It can be useful in industries where manual inspection is risky, slow, or difficult.

These projects connect engineering thinking with data, automation, and intelligent systems.
