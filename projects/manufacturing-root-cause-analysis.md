# Manufacturing Root Cause Analysis Assistant

Status: Work in Progress

Summary
---
An LLM-powered Industrial AI project that helps engineers find root causes for machine issues, quality defects, and production delays. It uses retrieval-augmented generation (RAG) to search maintenance logs, SOP documents, sensor summaries, and past incident records, then generates root-cause suggestions, corrective actions, maintenance tickets, and shift handover summaries.

Key Features
- Document and log indexing for fast retrieval
- RAG pipeline for context-aware root-cause suggestions
- Structured outputs: corrective actions, ticket drafts, and handovers
- Traceability links back to source records and evidence
- Evaluation: precision of suggested causes, time-to-resolution improvements
