# Health-Aware Robotic Fleet Optimization System

Status: Work in Progress

Summary
---
Built an Industrial AI system to manage multiple factory robots by assigning the right task to the right robot based on health, battery level, load capacity, location, availability, task priority, and flexibility score. The system plans optimal movement paths, helps avoid route conflicts, and tracks robot performance using metrics like idle time, waiting time, travel time, task completion rate, battery usage, congestion areas, and overall fleet efficiency.

Key Features
- Health- and battery-aware task assignment
- Location- and path-aware planning with conflict avoidance
- Dynamic reallocation based on real-time telemetry
- Fleet-level metrics and KPIs for performance monitoring
- Integration points for ROS, telematics, and factory systems

Notes
